# BIM-IFC-Single-Roads
Digital tools and supplementary files were developed for BIM-based monitoring and control of single-carriageway road construction projects using IFC 4.3.

This repository contains the digital tools and supplementary files developed as part of the Doctoral Thesis “Propuesta y validación de formato IFC para el control y seguimiento de obras de carretera de calzada única”, conducted at the Universitat Politècnica de València (UPV).

The repository supports the methodologies and developments proposed for BIM-based monitoring and control of single-carriageway road construction projects, including element segmentation, 4D–5D information integration, earthworks modeling, and the automated generation and parameterization of vertical traffic signs and road restraint systems. The developments also support the interoperability and exchange of model information using IFC 4.3.

The repository is organized into three main groups corresponding to the developments presented in Chapter 5 of the Doctoral Thesis:

Solid Segmentation and 4D–5D BIM Integration (Section 5.1): Dynamo scripts, input data, Property Set templates, and IFC configuration and mapping files.
BIM Tool for Earthworks (Section 5.2): parametric subassembly developed using Autodesk Subassembly Composer for the modeling and management of earthworks, particularly embankments.
Vertical Traffic Signs and Road Restraint Systems (Section 5.3): Dynamo scripts, input data, block libraries, BIM models, and IFC files used for the automated generation, parameterization, and validation of these road elements.

These files are provided to support the traceability, reproducibility, and future adaptation of the methodologies and computational developments presented in the Doctoral Thesis.
